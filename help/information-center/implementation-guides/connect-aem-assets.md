# Conectar o Adobe Commerce ao AEM Assets para gerenciamento de ativos

O AEM Assets pode ser conectado ao Adobe Commerce por meio de diferentes caminhos de integração, dependendo do produto Commerce.

Para o Adobe Commerce na infraestrutura em nuvem, use a Integração do AEM Assets para o Commerce. Para o Adobe Commerce as a Cloud Service e o Adobe Commerce Optimizer, use Visualizações de produto viabilizadas pelo AEM Assets.

>[!NOTE]
>
>Este guia aborda os caminhos de integração do AEM Assets para o Adobe Commerce na infraestrutura em nuvem, Adobe Commerce as a Cloud Service e Adobe Commerce Optimizer. Siga o caminho que corresponde ao seu produto e implantação.

## Introdução

1. Consulte a documentação da [Integração do AEM Assets para Commerce](/help/aem-assets-integration/overview.md) para obter os pré-requisitos e a configuração.


1. Para habilitar o gerenciamento de ativos com o AEM Assets, siga as [Próximas etapas](/help/aem-assets-integration/overview.md#next-steps) instruções para o seu tipo de implantação no _[Guia de Integração do AEM Assets para Commerce](/help/aem-assets-integration/overview.md)_.
